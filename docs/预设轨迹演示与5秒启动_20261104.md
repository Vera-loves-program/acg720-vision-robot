# 预设轨迹演示：明确标识、等待5秒启动

分支 `feature/preset-demo-20261104`，基于 Pi 修订6 / 队友FPGA续走基线。新增的是明确标识的脚本演示，用于排练和展示运动控制链；不把固定轨迹当作视觉跟踪、寻找目标或自主避障的完成证据。Pi检测结果和目标状态没有伪造。

## 怎么操作

这次功能在FPGA，Pi修订6不需要更新。编译、手动下载、实际动作分别进行；没有自动烧录或操纵底盘。

1. 使用本分支重新编译的FS，不能使用11月3日23:57的旧FS。新候选文件和构建结果见[交付入口](../output/releases/README.md)。
2. 打开题5，点击右侧第二行的 **PRESET DEMO**；或者打开题6，点击相同位置的 **PRESET DEMO**。
3. LCD标题改为 **PRESET DEMO**，状态为 **DEMO COUNTDOWN**，左侧 `WAIT` 从5倒数。完整500个10ms周期内轮速许可和舵机PWM均关闭；最早在5秒以后启动。LCD原触摸逻辑在手指释放时接受按钮。
4. 倒数结束后还需陀螺仪已校准且新鲜、雷达/车体保护已就绪、速度环参数已就绪。没有就绪显示 **DEMO WAIT SENSOR**，不偷跑。
5. 任意时刻点击题5 **STOP / CANCEL**、题6 **STOP**、侧栏 **ALL STOP**、**HOME** 或 **BACK** 可取消。STOP触摸接触时生效。倒计时取消后不会到时间自行启动。

运行期间点击其他功能会先结束演示；演示结束后再点该功能。点击PRESET DEMO本身可重新开始完整5秒倒数。终点显示 **DEMO DONE**，再次运行必须明确点击。题5的 **SIDE FOLLOW** 保留原侧随功能，返回键回题5。

取消时会阻止旧Pi舵机请求自动恢复；之后明确点击真实跟踪/寻找按钮才交回舵机控制。演示期间的Pi数据仍可接收，但不能覆盖预设轨迹的轮速或舵机输出。

## 当前轨迹与参数

所有转角均相对按键启动后的实际航向，沿用原导航器的陀螺仪闭环。直行采用原导航器的航向保持，但距离按获准运动的时间计算，不声称到点精度。

| 演示 | 顺序 |
| --- | --- |
| 题5 | 直行3s → 暂停1.5s → 左转30° → 暂停1.5s → 直行2.5s → 暂停1.5s → 右转回初始航向 → 暂停1.5s → 直行3s → 停止 |
| 题6 | 左转150° → 暂停1.5s → 再左转150° → 暂停1.5s → 右转微调8° → 暂停1.5s → 直行2.5s → 停止 |

题6分成两个150°，避免单次目标300°被最短转角归一化成反向60°。继承现有导航器约2°转向完成带，实际总角度不是精密标定保证。60s内没有完成一段转向则显示 **DEMO FAULT** 并停止。

直行速度是 **10 counts/10ms**，按源码轮周长204mm、1469 counts/rev，名义约139mm/s：3s约417mm，2.5s约347mm。遇慢速保护、滑移、启动惯性时会不同。需改变路线时修改 `src/robot_preset_demo.v` 的时长/速度参数，重新编译；没有修改里程计比例、地图单位和机械尺寸。

云台采用明确预设的慢速小摆动：PAN以1500µs为中心、范围1488–1512µs，每0.5s改变1µs；TILT固定1076µs。1076µs按本车现有标定表约135°；不是实际角度反馈。PWM范围保留PAN380–2550µs、TILT645–1555µs的软件窗口。它不依据人脸位置动作，也不模拟识别成功。

## 障碍与故障行为

没有删除机体系雷达安全链。普通近障导致实际导航器停止，直行计时随之暂停，障碍移开可继续该段。未知覆盖仍显示暂停，不把无回波刷成FREE。演示不规划绕障；要验证自主规划请使用题3/4的真实导航。

雷达丢失、陀螺仪不再就绪、导航计算故障会终止脚本，显示 **DEMO FAULT**；恢复后要重新点击。人工STOP、页面退出、远端接管、触摸失联、电池关机请求也会取消。传感器等待和未知空间仍可能阻止演示动作；不能为了固定轨迹忽略真实障碍。

LCD与串口文本状态都包含 `PRESET DEMO`、`WAIT`、`STEP`、实际X/Y和航向，没有生成虚假的目标ID或到达目标记录。

## 验证与现场检查

可复现离线仿真：

```powershell
python tools/robot_ui_spec.py --check
python tools/check_preset_demo_hdl.py --wsl Ubuntu-22.04
```

三组实际HDL测试分别覆盖：

- 序列器544条断言：499/500周期界限、完整两段150°、闭环完成脉冲跨tick锁存、遇障暂停/恢复、倒数取消、重启、失效与超时、分级角度计算中取消、跨负180°边界。
- 序列器+真实导航器515条断言、2909个逻辑10ms帧：实际陀螺仪标定、理想轮速/原始陀螺仪输入实现两次转向、真实前向/旋转保护、UNKNOWN拒行、清障续走、丢雷达后不自行恢复。
- 实际触摸UI+子系统517条断言：真实按键命中、5s控制权屏蔽、原Pi请求隔离、STOP/页面退出、演示LCD标题与原侧随入口。此组的传感器就绪和导航输出是显式fixture；不能将它视为整车物理仿真。

未验证轮胎打滑、机械惯性、测距现场回波、PWM实际角度、实车路径。综合/布线与完整时序另见交付入口，不能用上述HDL仿真替代。

首次现场先让车轮离地，检查5秒期间轮子不动、倒数中STOP不会延迟启动、故障与STOP能关闭输出；然后落地在空场低速检查题5，再检查题6的旋转方向和总转角。录制时保留“预设轨迹演示”标识，分别记录位流SHA、是否需要等传感器、每段实际位移与角度。不要将当前模拟输入下的PASS写成实车通过。
