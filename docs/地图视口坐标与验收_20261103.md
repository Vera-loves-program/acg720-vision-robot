# 地图视口坐标与验收（2026-11-03）

本次改动把**同一份底层地图快照**同时显示为全局图和局部放大图，不改变雷达安装外参、车体尺寸、避障距离或规划栅格。它尚需通过本轮完整构建和现场验收，不能用离线预览代替实车结果。

## 坐标与范围

底层仍为128×128格，每格64mm，原点偏移为(-4096,-4096)mm。有效世界范围为每轴 **[-4096,+4096)mm**；格索引为 `floor((世界坐标+4096)/64)`。先检查有效范围，再取7位地址；负值、4096mm及更远位置不会回绕到地图另一端。

世界+X在屏幕右方，+Y在屏幕上方。执行 `HERE IS ZERO` 后，当时车头为世界+X，轮轴中点O为(0,0)；此后转动车身不会旋转世界坐标轴。

| 显示 | 栅格/像素 | 世界范围 |
| --- | --- | --- |
| `GLOBAL 8.192M`，左图 | 128×128格，2×2像素/格 | 每轴[-4096,+4096)mm |
| `LOCAL 4.096M`，右图，`FIELD CENTER` | 64×64格，6×6像素/格 | 每轴[-2048,+2048)mm |
| `LOCAL 4.096M`，`CAR CENTER` | 同一地图内64×64格 | 随车移动，按下述公式限幅 |

点击 `FIELD / CAR` 切换局部图中心。每轴ROI起点 `r=clamp(车格索引−32,0,64)`，世界范围为 `[-4096+64r, -4096+64(r+64))mm`。例如r=0时为[-4096,0)，r=64时为[0,4096)。跟随以64mm格为单位，靠近地图边缘时保持视口在地图内部；小车未必位于画面正中心。无有效车位置时回退到场地中心。

`LOCAL 4.096M`是世界地图的裁剪视口，与系统在姿态/几何未就绪时使用的“本地扫描预览”不同。本地扫描预览固定车标于中心、隐藏世界目标和导航段端点，不能据此证明跨帧世界建图已就绪。

## 线框、标尺与标记

- 全局图的**蓝框**表示右侧64×64格ROI，跨度4.096m。
- 两图的**橙框**是固定世界参考场地 **[-2000,+2000]mm×[-2000,+2000]mm**，边长精确4m；不是62格或63格的近似，也不代表已经检测到场地墙。局部图只显示落在当前视口内的框线。
- `1.024M`标尺长度为16格，即全局图32像素；`64MM / CELL`标注物理分辨率。放大显示不会提高测距或定位分辨率。
- 红色十字为车位置，黄色箭头为车头方向的8方向显示；绿色十字为最终目标，青色十字为当前导航段端点。
- `CURRENT LEG`紫线只在车和当前段端点的**栅格X或Y相同**时连接两点。其他方向显示端点，不绘制伪造折线；这里没有完整BFS路径或历史轨迹缓存。

灰色为未知格，白色为FREE，青绿色为较弱占据，深色为较强占据；尚无有效快照时底图呈较深灰色。目标/端点在世界范围外、无效或被当前视口裁剪时不显示。全部标记和地图共用世界格坐标变换，叠加标记不写回地图。

## 已执行的检查与边界

Icarus Verilog 11实际执行了[生成RTL视口测试](../tests/tb_robot_map_viewport.v)，不是只运行Python坐标模型：**45,101次地址/单时钟数据检查、44,457次颜色检查、12次实际LiDAR避障模块模式对照通过**。覆盖全局全部格、场地/车中心ROI及两端限幅、负边界防回绕、精确4m框、车/目标/导航段同坐标变换。

避障对照实例使用实际 `lidar_body_guard` RTL：SELF回波100mm、远处回波1000mm及近障碍207mm；切换显示中心前后，阻挡/接触等输出及291mm旋转半径一致。207mm是雷达原点距离，对应该测试外参下车体点约(240,-77)mm，不是屏幕像素换算出的安全距离。

显示仍使用原有单时钟快照RAM读取。地图绘制带内保持读银行所有权，包括两图间隙和行消隐，带外才允许原握手换银行。测试中的银行所有者是接口模型：已检查两图不会因显示间隙请求换银行；**尚未据此证明完整异步CDC、亚稳态概率、板上时序收敛或所有规划场景**。UI静态8项及生成一致性检查也通过，但不能证明实际测距、里程计精度或绕障成功。

为缩短“屏幕坐标换算→车标比较→颜色寄存器”的路径，世界格坐标及有效位与RAM请求在同一像素边沿寄存；返回的地图格和车/目标/导航段比较使用同一拍坐标。没有增加RAM读取或LCD输出延迟。上述动态测试已在此调整后重跑，并逐点检查坐标寄存器与同沿RAM请求一致；是否满足45MHz仍以调整后的完整时序报告为准。

离线示例预览可由 `python tools/preview_robot_ui.py --html tmp/map-viewport-preview.html --png tmp/map-viewport-preview.png --view 2/1` 生成；其中地图和数字全部是示例。

## 两张现场照片怎么拍

1. **照片A：场地中心。** 在空旷区域停车，定义原点/+X后，放置一个雷达高度可见的独立物体，记录它相对轮轴中点O的位置。进入任务3的 `VIEW MAP`，选择 `FIELD CENTER`，等待稳定扫描后拍下整块LCD。照片应同时含全局图、局部图、蓝色ROI框、橙色4m框和标尺。确认同一物体在两图中对应同一世界格，右图每格宽为左图的3倍；不能把SELF车身回波当成外部障碍。
2. **照片B：小车跟随。** 保留同一原点和地图，不点击 `CLEAR MAP` 或再次归零。手动低速移动小车约0.5～1m后停车，选择 `CAR CENTER`，拍下同一画面；同时记录实际位移和物体位置。蓝色ROI应随车在全局图移动，局部图放大相应区域，物体的全局位置不应仅因切换视图跳变。切回 `FIELD CENTER` 后，全局地图及同一场景的避障诊断应一致。靠边时ROI限幅，不应从另一端出现物体。

两张照片都记录位流SHA、源码版本、拍摄时间及诊断导出。照片能检查显示、视口和现场建图现象，不能单独证明避障/规划判定相同；该结论还要对照相同场景的诊断值，并另做障碍物停车、导航续走及实际距离测量。
