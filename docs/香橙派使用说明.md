# 香橙派使用说明：R4 配套客户端

更新：2026-10-04。以后香橙派端只使用这份说明和 `acg720-orangepi.zip`。固定运行目录是 `/home/orangepi/acg720_vision`，入口是 `client.py`，不用再区分 V2、R4 等客户端文件夹。

FPGA 使用你已经烧录的 R4。本文直接配置和运行当前版本，不要求回退或做版本对照。

## 1. 这次 SSH 为什么超时

你的电脑日志显示：

| 设备 | 当前地址 | 所在网络 |
| --- | --- | --- |
| 电脑 Wi-Fi | 10.9.140.88 | 校园网 |
| 香橙派 Wi-Fi | 192.168.43.142 | 手机热点 |

电脑目前没有到香橙派手机热点的直连路径，所以 SSH 超时。现在改为 **电脑共享校园网给香橙派**，不用手机流量。Windows 已有 SSH 客户端，不需要安装 Windows Python，也不需要进入 WSL。

在电脑操作：

1. 电脑继续连接校园网，先确认浏览器能上网。
2. 按 Win+I，打开“设置 → 网络和 Internet → 移动热点”。这里是 **Windows 电脑热点**，不是手机热点。
3. “共享我的 Internet 连接”选择正在连接校园网的 **Wi-Fi/WLAN**，不要选 FPGA 测试用的以太网。
4. “共享方式”选 Wi-Fi。
5. 在属性里点“编辑”，把热点名设为 `Vera-OrangePi`，自己设置一个至少 8 位的密码。如果有频段选项，先选 2.4 GHz，点保存。
6. 开启“移动热点”。电脑继续连接校园网，不要断开校园 Wi-Fi。
7. 在香橙派点网络图标，选择 `Vera-OrangePi`，输入刚设的 **电脑热点密码**。此处不填校园账号。
8. 香橙派无线 IPv4 保持自动/DHCP；有线 `eth0` 的 FPGA 地址不改。

这是 Windows 自带的网络共享功能，设置位置见 [微软移动热点说明](https://support.microsoft.com/en-us/windows/experience/connectivity-networking/use-your-windows-device-as-a-mobile-hotspot)。网络来源是校园网，电脑热点本身不使用手机套餐流量。

香橙派连接成功后，运行：

```bash
ip -4 -br addr
```

找 `wlan0` 行，记录它的 IPv4。Windows 共享网络常见为 `192.168.137.x`，但必须以实际输出为准。以下用 `192.168.137.123` 举例，**不是要求把香橙派设置成这个地址**。

在电脑 PowerShell 先把这个变量换成实际查到的香橙派地址：

```powershell
$opiAddress = "192.168.137.123"
```

之后本文的 PowerShell 命令都使用 `$opiAddress`。关闭 PowerShell 后重新打开，需要重新设置这个变量。不要继续使用已经脱离的手机热点地址 `192.168.43.142`。

如果 Windows 提示无法开启热点，把错误提示发我；如果香橙派能连电脑热点但网页打不开，先确认共享来源选的是校园 Wi-Fi，电脑本身也仍能上网。不要反复重装 Python。

## 2. 两条连接分别负责什么

```text
校园网 ── 电脑 Wi-Fi ── Windows 电脑热点 ── 香橙派 wlan0
                      远程编辑、传文件、共享校园网

FPGA 网口 ─── 网线 ─── 香橙派 eth0：图像和控制数据
192.168.10.2          192.168.10.3/24
```

电脑热点连接不影响 FPGA 的有线连接。香橙派 `eth0` 保留 `192.168.10.3/24`，不填写有线网关或 DNS。电脑有线网口若也接入这个测试网段，使用 `192.168.10.4`；本次电脑不必接测试网线。电脑校园网地址与共享网络地址不同是正常的，Windows 会建立共享接口，不需要把电脑 Wi-Fi 改成香橙派的 IP。

你已说明香橙派选中校园 Wi-Fi 后要求账号/密码，输入后反复弹出窗口。这可能是企业认证失败，不能简单判断为密码输错。除了账号，还要匹配学校的 EAP 类型、内层认证、CA 证书/服务器域名和账号格式；系统时间错误也可能影响证书验证。具体配置应以学校提供的设置为准，不随意关闭证书校验。NetworkManager 的 [802.1X 设置说明](https://networkmanager.dev/docs/api/latest/settings-802-1x.html) 列出了这些独立字段。

如果仍要排查香橙派直连校园网，先尝试连接一次，随即在香橙派运行下面的只读命令，保留失败原因：

```bash
nmcli -f GENERAL.STATE,GENERAL.REASON device show wlan0
sudo journalctl -b -u NetworkManager -n 60 --no-pager
date
```

提供学校名称、Wi-Fi 名称、认证窗口的字段和错误行即可，账号可以遮住，不发送密码。电脑热点共享校园网可先完成开发，不需要等直连认证修好。

## 3. 香橙派启用 SSH

以下在 **香橙派终端**运行，提示符一般是 `orangepi@orangepi5`：

```bash
sudo systemctl enable --now ssh
systemctl is-active ssh
```

看到 `active` 就继续。如果提示 `Unit ssh.service could not be found`，需要安装服务器：

```bash
sudo apt update
sudo apt install openssh-server
sudo systemctl enable --now ssh
```

如果 apt 又出现之前的 `Hash Sum mismatch`，先按第 5 节处理软件源；可以先通过 U 盘把本次唯一的 ZIP 放到香橙派。

接着在 **电脑 PowerShell**运行：

```powershell
Test-NetConnection $opiAddress -Port 22
ssh "orangepi@$opiAddress"
```

`TcpTestSucceeded: True` 表示 SSH 端口已通。第一次连接会显示主机指纹；可在香橙派执行 `sudo ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub` 核对。确认是你的设备后输入 `yes`，再输入香橙派账户密码。密码输入时不显示字符。

成功后电脑终端会变成 `orangepi@orangepi5`。输入 `exit` 返回 PowerShell。

如果电脑已接热点且 SSH 为 active，仍然超时：

1. 再核对 `wlan0` 的当前 IP，不沿用已变化的地址。
2. 在香橙派运行 `ss -lnt | grep ':22'`，确认服务在监听。
3. 在香橙派运行 `sudo ufw status`。若防火墙 active 且禁止 SSH，可运行 `sudo ufw allow OpenSSH`；若 inactive，则不需要改它。
4. 确认香橙派连的是电脑的 `Vera-OrangePi`，不是仍连接手机或尝试校园 Wi-Fi。电脑移动热点必须保持开启。不要为此修改 FPGA 的 IP。

## 4. 安装这一个客户端包

### 4.1 把 ZIP 传到香橙派

电脑上的固定文件是：

```text
D:\GOWIN_PROJECTS\deliverables\acg720-orangepi.zip
```

SSH 已通时，在 **电脑 PowerShell**执行：

```powershell
scp "D:\GOWIN_PROJECTS\deliverables\acg720-orangepi.zip" "orangepi@${opiAddress}:/home/orangepi/"
```

如果 SSH 还未安装，这次先用 U 盘把 ZIP 复制到香橙派主目录 `/home/orangepi`。使用文件管理器的 Home，不是打开压缩包后就算解压了。

### 4.2 解压，只在香橙派执行

先确认主目录没有已经被你修改过的 `acg720_vision` 目录。第一次安装时执行：

```bash
cd ~
python3 -m zipfile -e ~/acg720-orangepi.zip ~/
cd ~/acg720_vision
ls
```

应看到 `client.py`、`pc`、`tools`、`README.md` 和 `manifest.json`。`pc` 内的几个 Python 文件是配套模块，都要保留，但日常不需要分别启动它们。

旧 V2 目录先不动。新目录确认能运行并保留照片后，再按第 8 节清理。

## 5. 软件环境只安装一次

香橙派已有 Python 3.10。先试：

```bash
python3 -c "import cv2, numpy; print('Dependencies OK')"
```

若显示 `Dependencies OK`，可以直接进入第 6 节，不重复安装。

若提示缺少 cv2/numpy，运行：

```bash
sudo apt update
sudo apt install python3-opencv python3-numpy openssh-server
```

出现 `y/n` 时输入 `y`，回车。这里使用香橙派系统 Python；不再建立 V2 等多个虚拟环境，不复制电脑 WSL 的虚拟环境。

**如果依然出现原来的下载校验错误**，使用包里自带的阿里源工具：

```bash
cd ~/acg720_vision
python3 tools/fix_orangepi_apt.py
sudo python3 tools/fix_orangepi_apt.py --apply
sudo apt clean
sudo apt update
```

第一条只预览，第二条先备份再修改 Ubuntu Ports 地址，保留香橙派厂商源和签名设置。工具会打印备份位置。香橙派 Ubuntu 22.04 ARM64 使用 `ubuntu-ports`，配置参考 [阿里云 Ubuntu Ports 镜像说明](https://developer.aliyun.com/mirror/ubuntu-ports/)。

`apt update` 成功后再运行安装命令。若仍失败，把实际错误发我；不要关闭软件包校验。先确认香橙派通过电脑共享的校园网能正常打开网页，不使用手机流量下载依赖。

安装完成后再次执行上面的依赖检查。

## 6. 日常只记住两个启动命令

### 看实时画面

在**香橙派自己的桌面终端**执行：

```bash
cd ~/acg720_vision
python3 client.py view
```

程序自动绑定 `192.168.10.3:6102`，接收 FPGA `192.168.10.2` 的图像和 R4 状态数据。按 Q 退出。

### 拍照片

先退出查看器，再在香橙派桌面终端执行：

```bash
cd ~/acg720_vision
python3 client.py capture
```

拍照窗口出来后：

1. 等摄像头画面出现，点击一下画面窗口，让键盘输入进入这个窗口。
2. 按 `1` 选你的照片（`vera`），按 `2` 选小狗玩偶（`dog_plush`），按 `3` 选耳机线（`earphone_cable`）。这是保存分类，不是自动识别。
3. 按空格或 C，开始 **5 秒连拍**，默认最多每秒 3 张，约 15 张。期间可以改变角度、距离和光线。
4. 看到 `BURST DONE` 后再开始下一轮。约 10 轮可以接近 150 张，实际以保存数为准；不要为了凑数全拍几乎相同的画面。
5. 按 Q 退出。

所有照片固定保存到：

```text
/home/orangepi/acg720_vision/dataset/captures/
```

每次启动生成独立的时间目录。PNG 是收到的完整 400×240 图像，不包含电脑 UI。实际照片保留 FPGA 已输出的预处理效果，不通过软件再模拟滤波。

程序记录你已烧录的 R4；滤波状态仍需以 LCD 当前状态为准，UI 状态包与每一帧没有一一对应的确认。如果 LCD 明确是 GAUSS ON 且拍摄期间保持不变，可使用 `python3 client.py capture --filter on` 记录人工确认的状态。

同一时刻只开一个接收程序：查看器、拍照程序和收包工具不能同时抢占 6102 端口。

若窗口仍等待画面，可以只检查当前 R4，不换 FPGA 版本：

```bash
python3 client.py probe
```

把输出发我即可。换一个目录或安装图像库不会修复发送端可能存在的包格式问题。

## 7. 电脑 VS Code 直接改香橙派文件

先完成第 3 节的普通 SSH 登录，再操作 Windows 版 VS Code：

1. 左侧扩展，安装 Microsoft 发布的 **Remote - SSH**。
2. 按 F1，选择 `Remote-SSH: Connect to Host...`。
3. 输入 `orangepi@实际香橙派WiFi地址`，例如 `orangepi@192.168.137.123`。此处填实际地址，不填 PowerShell 的变量名，也不原样填中文占位词。
4. 系统类型选择 Linux，按提示输入密码，等待连接完成。
5. 新窗口左下角显示 SSH 后，File → Open Folder，输入：

```text
/home/orangepi/acg720_vision
```

6. 按 Ctrl+S，文件直接保存到香橙派。Terminal → New Terminal 打开的也是香橙派终端。

微软提供了 [Remote-SSH 连接和打开远端目录的说明](https://code.visualstudio.com/docs/remote/ssh)。不需要在香橙派反复安装新的编辑器。

**远程终端不会自动把 OpenCV 窗口显示到电脑。**当前 `view` 和 `capture` 在香橙派连接显示屏的桌面终端启动；`probe` 没有图形窗口，可以在电脑 SSH 终端运行。

SSH 后台拍一次也可以，用这个命令代替 GUI：

```bash
cd ~/acg720_vision
python3 client.py burst --class dog_plush
```

它立即开始 5 秒采集，结束后退出，照片仍保存到同一位置。

## 8. 旧 V2 等目录怎样清理

先确认新的 `~/acg720_vision` 能启动。保留已经拍摄的照片；查看旧目录是否还有自己改过的代码。

从旧 V2 合并照片到固定目录，可在香橙派执行：

```bash
mkdir -p ~/acg720_vision/dataset
if [ -d ~/acg720_vision_client_v2/dataset ]; then
    cp -an ~/acg720_vision_client_v2/dataset/. ~/acg720_vision/dataset/
fi
```

这只复制照片目录，已有同名文件不覆盖。其他旧目录如果也有照片，用文件管理器复制到固定目录，确认文件都在。

随后在香橙派文件管理器的 Home 中，将旧 V2、旧接收目录和旧 ZIP **移到回收站**。未保存的代码先备份。先不要清空回收站，日常只打开 `acg720_vision`。以后无需保留多套运行目录，也不需要重复创建环境。

我目前没有 SSH 登录到你的香橙派，这一步由你在香橙派完成；电脑侧这次只生成统一包和说明，没有删除任何旧工程或照片。

## 9. 以后更新只覆盖程序，照片留在固定目录

以后我提供的客户端仍叫 `acg720-orangepi.zip`，目录仍叫 `acg720_vision`。内部 manifest 记录版本，但你不需要换文件夹。

先退出接收程序。如果你在香橙派改过程序，先保存这些修改，再更新。电脑 PowerShell：

```powershell
scp "D:\GOWIN_PROJECTS\deliverables\acg720-orangepi.zip" "orangepi@${opiAddress}:/home/orangepi/"
```

香橙派终端：

```bash
python3 -m zipfile -e ~/acg720-orangepi.zip ~/
cd ~/acg720_vision
python3 client.py view
```

包里不放 `dataset`，解压更新会覆盖同名程序文件，不删除照片，也不重建 Python 环境。VS Code SSH 的修改不会自动同步回电脑或 GitHub，更新前仍要先保存自己的代码修改。
