# 香橙派客户端：公开说明

当前 FPGA 工程只使用 R4：`vision_robot_ui.gprj`，客户端只使用 `client.py`。旧项目入口及重复操作文档已整理，Git 保留历史。

这是不包含实际校园网、主机地址和个人部署配置的公开简版。完整逐步操作指南保留在使用者电脑的 `deliverables/香橙派使用说明.md`，客户端 ZIP 中的 README 与该本地指南一致。请按自己的接口和地址配置运行环境。

客户端提供四个入口：`view` 显示视频，`probe` 检查协议和完整帧，`capture` 交互式采集，`burst` 无窗口连拍。图形入口应从香橙派桌面启动，普通 SSH 不会自动转发窗口。传文件的命令应在源文件所在电脑运行；SSH 登录后的终端操作远端设备。

照片保留在固定客户端目录的 `dataset` 内，不上传公开仓库。旧目录必须检查个人代码和照片后才能清理，建议先移入回收站。客户端依赖为 Python、NumPy、OpenCV；ARM Linux 环境与电脑虚拟环境不能直接互拷。

通信测稳后，先查各传感器模块的供电、逻辑电平和协议，再验证模块和冻结接线表，最后设计转接 PCB。既有 LCD、摄像头、DDR3、网口等映射保留。扩展接口与 HDMI 可能共享管脚，需核对原始板卡原理图和目标器件约束，不能仅按未使用的 CST 管脚推断可用性。

HDMI 是接口，LCD 是面板类型。换 HDMI 不会自动改善 UI；复杂控件和字体能力主要来自渲染程序。建议先保留正常工作的 FPGA RGB LCD，用现有香橙派显示器开展软件界面开发；如需测试 FPGA HDMI，先用现有显示器验证适配，再确定触摸与转接板方案。

公开仓库仅包含自编维护文件，厂商依赖、个人照片和位流保留在本地。不是完整厂商工程备份。
