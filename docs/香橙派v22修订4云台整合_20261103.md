# Pi v22修订4：队友云台速度整合（2026-11-03）

本包用于替换Pi应用代码，不重刷系统，不包含现场`config/gimbal.json`、`config/visual_task.json`和模型。以实际manifest版本22、修订4及运行日志/文件哈希确认加载；网页从运行状态显示“v22修订4”，去掉遗留v18标题。本次代码来源为本机实测基线与`D:\teammate‘s\acg720_vision`的v22修订3，并补充类别调度/网页与LCD选择冲突修复；没有代理部署或设备动作。

## 整合内容

1. 合入队友三档速度：同时调整PWM变化率、跟随增益和最大角速度。只在用户点“应用速度”时保存，不覆盖原有角度表和限位，也不默认为快速启动。
2. 合入人脸置信度迟滞：默认≥0.5才能新锁定或重锁；已有连续人脸可以在≥0.4时维持。DOG仍保持原0.5跟踪门槛，不随人脸放松。
3. 原先小狗和人脸推理串行执行，截图约135+32=170ms。现在明确的FACE任务只跑人脸、DOG任务只跑小狗；空闲预览仍检测两类。画面标出FACE/DOG/BOTH与skip，切换时丢弃旧类别迟到结果，避免把旧框用于新任务。
4. 网页显式选择目标时清除旧LCD选择及自动搜索/侧随状态，暂停等待用户重新开始。原来LCD先锁DOG、网页再选FACE时，会继续按旧DOG类别过滤人脸帧；已修正该控制权冲突。
5. 保留135°准备姿态、90°下限、LCD三帧新画面确认、UDP协议、现有模型和标定。仍采相机最新帧；没有迁入新相机驱动或换模型。

| 速度档 | 每轴PWM变化率上限 | 跟踪角速度上限 |
| --- | ---: | ---: |
| 慢速 | 150μs/s | 25°/s |
| 标准 | 600μs/s | 45°/s |
| 快速 | 1200μs/s | 75°/s |

这些是指令上限，实际速度还受角度表、图像处理、机械行程及舵机响应影响，不是实测转速保证。

## 安装与确认

只使用本次独立更新包`acg720-orangepi-v22-r4-code.zip`，保留已有v22修订2原包以便回溯。电脑上传至Pi的`/home/orangepi/`；SSH地址沿用当前能连接的有线或无线IP。

在**Pi SSH终端**执行：

```bash
cd /home/orangepi
unzip -o acg720-orangepi-v22-r4-code.zip
cd /home/orangepi/acg720_vision
python3 -c "import json; m=json.load(open('manifest.json')); print('version=',m['client_bundle_version'],'revision=',m['bundle_revision'])"
sh tools/start_fpga_follow.sh --restart
sh tools/start_fpga_follow.sh --status
```

应输出version=22、revision=4，服务运行且日志显示本修订；仅解压成功不能证明旧进程已替换。不要另外叠加旧nohup。旧Shell换行修复仍保留，交付ZIP内脚本必须为LF。

首次网页测试：停车→打开“目标跟踪”→速度选“标准”→点“应用速度”→重新选择人脸→“开始跟踪”。页面显示真实已存PWM变化率和角速度，不能只看下拉框。应用速度会暂停跟踪，不会偷偷继续移动。确认方向和跟随稳定后再比较“快速”。

LCD测试：先在网页保存速度，然后结束完整网页，从LCD题5点TRACK FACE；电脑另开只读`/stream.mjpg`观察。完整网页关闭/刷新可能发送disable，所以不要在LCD跟踪中途关闭它；若已关闭导致停止，从LCD重新启动，不用重启整机。

## 现场测试分开做

1. 底盘停车，先保持现有角度表、图像校准、限位和模型。先用人脸，确认左右跟随方向正确，再比较速度档。不要为了追不上直接扩大PWM范围。
2. 初始TILT仍请求135°，运行不低于90°；通过现场角度表换算，不用固定969/2100等脉宽代替机械角度。没有真实舵机角度反馈，日志角度是指令估计。
3. 截图PAN=380μs恰为记录下限，不能只靠增加速度解决越限方向、机械行程或零位问题。先确认当前位置与目标方向是否还存在可用行程；若持续向反方向冲限位，保留日志和标定后定位控制方向，不凭照片猜反号。
4. 无选定目标时预览仍可显示两类检测；独立人脸跟踪时应检查人脸处理是否被小狗推理串行拖慢。切换到DOG后要等新帧与当前类别目标，不能继续使用上一个人脸框。
5. Pi的以太网仍连FPGA，电脑通过Wi-Fi SSH隧道看`http://127.0.0.1:18080/stream.mjpg`。完整网页的关闭/刷新会发送关闭PWM指令：LCD跟踪时先结束完整网页，再从LCD启动，只看独立视频流。

本工程与队友的正常FPGA视觉PWM输出链、FOL/TGT/VEC/GOL/RBT协议一致；正常robot_follow_pwm模块字节SHA相同。实际HDL8项验证600μs阶跃下一20ms帧完整应用、50clock/μs、停用与非法边界，不存在1μs/frame二次限速。该慢速限制属于独立执行器测试模块，正常视觉链不经过它。**本次云台速度整合无需另改FPGA位流**；雷达建图/左绕修订另有单独位流和未闭合时序记录。
