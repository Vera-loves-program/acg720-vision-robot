# 视觉交互预览：电脑 / 香橙派接收窗口

这一版扩展 `pc/udp_video_viewer.py` 的交互功能。它运行在电脑或香橙派桌面上；FPGA 的 1024×600 LCD 触摸交互由另一部分代码实现，不能把两个窗口混为一谈。

## 运行

在已经能收到 FPGA 图像的 WSL / 香橙派终端、项目目录中，使用原来的虚拟环境运行：

```bash
/home/Vera/.venvs/acg720-vision/bin/python pc/udp_video_viewer.py --bind 192.168.10.3
```

上面是已核对存在的电脑 WSL 环境；香橙派使用它自己的 Python 环境。当前接收图像为 **400×240、RGB565**；800×480 是窗口放大显示尺寸，不表示网络传来了 800×480 的细节。

## 操作

| 操作 | 结果 |
|---|---|
| 单击侧栏 `VISUAL DEBUG`，或按 D | 进入 / 退出本地视觉调试模式，同时发送原有 FPGA 调试开关请求 |
| 调试模式下双击画面 | 标记选择点和一个 80×80 的初始候选区域，保留原始 400×240 坐标 |
| 鼠标指向画面、滚动滚轮 | 在 1～4 倍之间改变预览缩放，尽量保持指针所指位置不变 |
| 单击 `RESET VIEW`，或按 V | 恢复完整画面、1 倍显示 |
| 单击 `CANCEL TARGET`，或按 C | 取消已选择的目标 |
| 单击 `GAUSS REQUEST`，或按 F | 发出启用 / 禁用高斯滤波的请求 |
| `REQUEST STOP` / E、`REQUEST CLEAR` / R | 发出原有协议的停止锁存 / 清除请求；本版本尚未接入电机断电 |
| Q 或 Esc | 退出接收窗口 |

现在选择目标后会明确显示 `TARGET SELECTED` 和 `TRACKER NOT CONNECTED`。选择框是用户指定的候选区域，不是检测算法给出的物体边界，也不会自动跟着人物移动。后续接入检测器 / 跟踪器时，应读取 `TargetIntent` 中的点、候选区域、图像尺寸和时间，再单独回报“跟踪有效 / 目标丢失”。

滤波、调试和停止请求使用原来的 `VRB1` 八字节命令。FPGA 当前不回传确认，因此侧栏只显示“请求值”，不会把它当作已经生效的状态。采集数据时以 LCD 实际状态及固定采集约定为准。

R3 固件另提供 `VUI1` 触摸 / UI 状态包，和视频共用 UDP 6102 端口。查看器会显示最近观测到的 FPGA 滤波、触摸和停止锁存状态；这不是某一张图像的状态确认。若三秒没有新状态包，会标记为过期。R2 固件没有状态包，原来的收图和鼠标操作仍可使用。

运行交互固件时，LCD 双击选点会换算为网络图像坐标并在此窗口标记目标；缩放状态会使这个接收窗口切换 1 / 2 倍中央区域预览，取消操作会清除标记。首次收到状态包只同步状态，不重放之前的拍照按钮操作。如果此时正在运行查看器，LCD 的拍照请求只会提示使用采集工具；要用 LCD 触发五秒连拍，请退出查看器并运行 `capture_dataset.py`。

旧 R3 的 LCD 只发送主机缩放请求，屏上没有放大像素。**R4 已加入 LCD 本地放大代码**：中央 400×240 原图区域放大成 800×480，由用户重新编译上板验证；网络图像仍为完整 400×240。新查看器收到 R4 的实际倍率后，也围绕画面中心裁剪，保持两端观看区域一致。电脑 / 香橙派的 `CANCEL TARGET`、`RESET VIEW` 若在最近三秒收到过交互状态包，还会分别发送命令 5 / 6，请求 LCD 同步清除选点 / 恢复视图；没有状态包时只执行本地操作，兼容已运行的 R2 固件。鼠标滚轮仍可单独围绕指针缩放主机画面，并不反向设置 LCD 倍率。

## 缩放与拍照

此处缩放只是电脑 / 香橙派窗口的数字裁剪和放大，不增加图像细节，不改变 FPGA 发送的像素。选择框和所有 UI 文字也不会写入原始接收图像。

拍摄训练照片请使用 `pc/capture_dataset.py`。先退出这个查看器，再开启采集脚本；两者使用同一个 UDP 6102 端口，不能同时抢收数据。采集脚本保存网络收到的完整图像，不保存这个调试窗口的截图。

如果画面超过两秒没有更新，会显示 `VIDEO STALE` 并拒绝在旧画面上创建新的目标选择。没有接收到完整画面前，同样不能选目标。

## 验证范围

坐标映射、缩放边界、候选区域、取消操作及命令编码有 Python 单元检查。已用本机现有 WSL OpenCV 环境实际绘制普通/放大预览，检查排版与原图像素不变；现场鼠标输入仍需在电脑 / 香橙派桌面确认。本项没有进行 FPGA 编译、仿真或电机测试。
