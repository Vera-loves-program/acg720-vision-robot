## 3. 实测几何和电池

两驱动轴中点O，+X车头/+Y车左，A端车头、B端云台车尾。雷达测距核心R在O前32.56mm/右77.35mm，源码(+33,-77)。完整无突出部件外廓前231.27/后117.39/左右119mm，向外取232/118/119/119。行驶50、转向100、虚拟接触10mm；转向圆半径261+100=361mm。所有值可在LIDAR INSTALL在线改；ZERO还需车头纸板核验。

轮径65mm、周长204mm、轮距213mm、共用CPR1469（10圈L14683/R14690）。两轮速度P30/I1/D0、PWM60%是用户已调值，复位不保存，要用VOFA恢复。

两块12V标称18650/2800mAh电池。A83/B88映射为显示100%，单点映射不等于库仑容量/电压完整校准。A映射≤20%有效持续5秒请求Pi正常关机，也可LCD手动请求；30秒后FPGA只是输出锁定，不是电源切断。BQ板级设置曾基于240kΩ/16.5kΩ、3S、初始Divider15545；外部10k B3950温度曲线仍未完整校准。不要自动执行BQ SETUP、学习或改化学模型；旧DF审查和电压异常细节在历史原件第32～34节。

### 37.3 通行和旋转的几何检查



静态候选中心线依次为`A—B—C—D—E—F—G—H—A`，其中无障碍时H仅为南侧中心线中间位置`(2.00,0.65)`。东西通行带真实宽度为1.40m，南北分别至少1.60m；语义地垫本身不减少净空。实体布置新增窄口时，建议起步不小于0.80m，并单独复核转弯。



30×50cm矩形围绕几何中心原地旋转的最远角点半径为`√(0.15²+0.25²)=0.29155m`。本稿额外给出0.10m物理净空、0.10m定位误差预算，保守按圆形膨胀半径`r=0.49155m`检查。**0.10m定位余量是设计假设，不是实车已达到的定位精度。** 驱动轴不在几何中心、线缆/轮胎/云台突出、轮子打滑或误差大于预算时，须增大包络重新验算。



独立Python几何计算检查了八条轴对齐中心线到围挡及固定箱体的最短距离，全部通过；最小原始距离为0.65m，减去上述包络后尚余0.15845m。该圆包络包含0～359°逐度旋转的矩形四角，因此覆盖图中停车点原地转向的名义几何扫掠。它不证明定位、制动或控制已经实现，动态停车距离仍应实测，不能让软件一直顶着箱体试转。



临时40×40cm箱放在`[1.80,0.45,2.20,0.85]`，占住H区中心线。相同检查得到仅`A—H`、`H—G`被阻塞，其余绕行边仍通行：



- 无临时障碍：`A→G`南侧直达，中心线2.70m。

- 有临时障碍：`A→B→C→D→E→F→G`，中心线8.10m。任务点可选择仅经过，不必每点都执行任务。

- 若正在行驶后才放箱，应先减速/停车并确认重规划，再选择替代边；未确认自由的空间不能仅凭“地图上应当没有箱子”继续前进。

- 人员或箱体封住另一侧、剩余通道不足时，正确行为是停车并报告暂时不可达。



### 37.4 地图如何存在FPGA里，以及怎样逐步完成



至少保存三类数据：**几何地图**表示哪儿有围挡/箱体，**语义任务表**表示某个区域叫什么、目标坐标/朝向及到达后动作，**动态观测**表示现在新增了什么障碍。它们可以叠在同一张图显示，但来源和更新方式不同。2D雷达在其高度平面测到墙和箱体，编码器/IMU估计车移动了多少；将观测与已知几何匹配才是在修正自己的位置。地面地图图像只是数据表示，存入PNG或像素本身不会产生定位能力。



本稿先用已量好的围挡/纸箱尺寸生成静态地图，不把“在线SLAM、自动探索未知地图”作为11月4日前导航的前置条件。5cm栅格为80×80=6400格，2bit/格的静态状态仅1600字节；雷达扫描缓存、定位搜索、路径规划工作数组及日志另算，不能只用这1600字节宣称算法已放得下。语义区可用八条矩形范围和任务记录保存，无须给每格存汉字。



建议按能独立演示的顺序实现：



1. **几何与运动标定**：测轮径、轮距、编码器分辨率和轴/雷达偏移；先完成左右轮速度闭环及低速停车。

2. **固定起点路径点**：人工摆正A点，编码器增量+IMU航向估计位姿；先走A到G短线、再走整圈，记录误差。开环按时间转弯不能代替定位。

3. **雷达接收与保护停车**：检查帧/距离有效性，计算前方障碍区；数据超时/无有效量测时采用明确的降速或停车策略。近距离或扫描平面外障碍由已有TOF/超声补充，具体覆盖需实测。

4. **已知地图定位校正**：利用四周边界和中央L形对编码器/IMU预测位姿做小范围匹配，逐步加入方向/距离修正。初版固定A点起步，暂不要求任意搬动后全局自动恢复。

5. **动态绕障与语义任务**：先做八节点路网的边阻塞与绕环重规划，再从名字查坐标，到达后调用视觉/交互功能；全场栅格A*、更自由的局部绕行可在稳定后扩展。



以上只是实施计划，没有新增导航RTL、启动HDL编译/仿真或给实车下发运动命令。本节产物是坐标/净空方案、静态几何检查和SVG布局。
