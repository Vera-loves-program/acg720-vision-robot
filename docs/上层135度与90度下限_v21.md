# v21：上层实际135°，工作角度不低于90°

本次按用户最后确认的要求，只改变上层TILT工作范围：开始跟踪/搜索时实际转到135°；自动跟踪、搜索、手动命令和发给FPGA的PWM限位均不允许低于90°。PAN起点仍是1200μs，不增加180°修正，不修改原标定、模型或相机车头参考。

135°通过现场`config/gimbal.json`的实测角度表换算成PWM，不能继续用旧的`--initial-tilt 2100`命令代替。原角度表完整保留，90°下限仅是运行范围；PWM边界向范围内部取整。缺少覆盖90°～135°的有效标定时程序说明原因，不猜PWM。

包不包含现场`config/gimbal.json`或模型，不覆盖它们。启动器会停止旧的实际视觉进程，等待8080/6102端口释放再启动；已有本项目开机服务时会更新它的135°启动参数。它不会自动选目标或启动底盘。

查看状态：`sh tools/start_fpga_follow.sh --status`。正常启动后把网线接回FPGA，再在LCD点击对应跟踪/搜索操作。上层角度修改在Pi端，无需为了这一项单独重编FPGA；导航修复则需要对应的新位流。
