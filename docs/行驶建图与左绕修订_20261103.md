- 一张显示当前位置约(246,4)mm、航向约6°，目标(300,0)mm。还差54mm，不满足最终双轴5mm接受条件；它没有显示ARRIVED。

## 已找到并修改的代码问题

### 1. 基础速度30会停掉世界地图采集

旧`world_map_pose_valid`同时依赖`correction_allowed`及其pose_update锁存值。原校正门限是每10ms平移不超过2mm、转动不超过0.2°。按现有实测轮周204mm、编码器1469COUNT/圈，30COUNT约4.17mm/10ms，超过2mm。结果是采集状态机丢弃未完成扫描，保留旧world cells；BODY雷达安全链仍独立更新。

现在把两种资格分开：

| 用途 | 条件 |
| --- | --- |
| 逐点世界投影`mapping_allowed` | 每10ms平移≤8mm，覆盖当前30COUNT巡航；8mm为64mm地图细格的1/8 |
| 扫描匹配校正`correction_allowed` | 保留原2mm/10ms限制，不允许移动采图资格自动授权位置校正 |

两者仍检查姿态有效、无故障及原0.2°/10ms角速度界限；世界投影仍要求独立陀螺仪年龄<30ms、100Hz一致pose新鲜。转得过快时世界图仍可能暂停写入，BODY扫描继续，不能宣称所有转向中都逐圈积分。8mm是工程采集界限，不是实际建图误差保证。

实际HDL用真实navigation累计编码器、源码抽取的资格锁存、真实guard和真实mapper验证：30COUNT时新图提交新scan ID，旧资格的并行负对照mapper仍无积分；同步规划读口分别读到新FREE、旧UNKNOWN。23项覆盖正负57/58COUNT边界、过转、gyro新鲜度/失效、编码器故障，以及BODY继续工作。测试tick部分加速，不是整车运动精度测试。

### 2. `NO KNOWN PATH`掩盖了其他任务错误

旧诊断条件`no_path || effective_planner_error==4`把任务暂停总标志当成BFS无路。于是最后精确段被阻挡、传感器异常、运动许可不足等也会覆盖成NO KNOWN PATH。现在只有有效规划错误4显示该无路原因，其他情况保留具体错误。

实际诊断寄存器/优先级源码抽取与真实状态文本模块验证27种完整状态行；恢复旧条件的临时负对照按预期失败。真实mapper+planner另验证3个场景、473,598次同步读应答：已知FREE的(246,4)→(300,0)可达，起点实际占据和UNKNOWN仍分别拒绝，未复现地址/同步读延迟错配。

主机诊断工具也改为明确打印nav_status/nav_fault/mission_error/planner_error、积分编号、world_capture、首拒绝细格与pose/goal。reason0改为“当前无分类的实时拒绝原因，请看任务/规划错误”，不再暗示导航已ready。历史触发点仍明确标记可能为历史。

### 3. 优先左绕

按用户最新选择，BFS同长路线的邻居顺序改为车前→车左→车右→车后。保留最短路和FREE/扫掠体检查；左侧不可用时可以右绕，不强行左转。实际planner回溯测试四个初始航向，均选择车体系左侧；左侧占据或UNKNOWN时仍能选右侧已知通路。共18项断言。它是路径平局偏好，不是连续曲线局部规划器。

### 4. 前瞻包络增加一拍，缩短已测长路径

最终15:23报告的控制同域最差路径经过位置减法、绝对值、目标包络、雷达前瞻到NAV模式。将33位包络寄存，保持完整数值范围；新GO、地图清除、转向、传感器无效与恢复首拍屏蔽旧包络。独立BODY极近/接触硬停车链没有增加延迟。实际guard→源码前瞻→真实navigation验证1608项，覆盖三种GO来源、旧长目标切新短目标和33位极值；能否改善布局布线后时序仍看本轮新报告。

## 保留的问题和边界

1. **不删除碰撞和故障停车。** 有普通障碍时保留目标、寻找已知可行的左侧或其他路径；无可靠通路或传感器/硬件故障时仍停车。清障后靠新的合格地图及实时传感器恢复；不承诺任何环境都必须持续运动。
2. **地图仍接收未确认的有效点。** 实际guard→mapper→planner复现：一个非SELF、非10mm极近、未获邻束确认的点可把FREE置为暂态`10`，规划器仍会拒绝起点；下一有效远射线可清回FREE。该保守策略未偷偷改成可通行，也没有把UNKNOWN刷FREE。没有现场日志不能认定照片就是这一种情况。
3. **当前真实起点仍使用291mm旋转圆**，粗节点和连接仍保守检查；未新增任意朝向矩形的精确小角度扫掠规划。狭窄处可能继续拒行，不保证“看起来空旷”就一定能走。
4. **显示和规划分开。** 规划器读live cells RAM，不读LCD快照bank；freeze释放后可继续积分。NAV切到MAP会取消任务，但不会仅因切页直接清除/冻结world map。显示仍只画当前轴向段，不新增完整BFS路径缓存。
5. **没有新实车验收。** 原候选未时序闭合；本修订的资源/时序与发布路径以新构建记录为准，不把HDL PASS当作板上通过。
