# v22：135°工作姿态、人脸与小狗独立跟踪

当前包为v22修订2，启动脚本固定使用Linux LF换行。早先v22包有两个脚本带Windows CRLF，导致`set: Illegal option -`，服务无法正常重启、LCD等待Pi连接。已解压旧包时，无需再次上传，在Pi SSH中直接修复：

```bash
cd /home/orangepi/acg720_vision
python3 -c "from pathlib import Path; [p.write_bytes(p.read_bytes().replace(b'\r\n', b'\n')) for p in Path('tools').glob('*.sh')]"
sh tools/start_fpga_follow.sh --restart
sh tools/start_fpga_follow.sh --status
```

应看到`active (running)`及`FOLLOW runtime:`等启动日志，再把网线接回FPGA。若服务仍未正常运行，保留输出排查，避免反复叠加启动旧nohup进程。这次只修复Pi打包与脚本格式，不需要为此重新编译FPGA。

你上次贴出的运行记录明确是v20，服务参数仍为`--initial-tilt 2100`。只烧录FPGA不会更新Pi上的Python或服务。本包不包含现场标定、相机车头参考或模型，因此不会覆盖它们。

电脑PowerShell，网线接电脑和Pi时：

scp D:\GOWIN_PROJECTS\acg720_vision_robot\output\releases\acg720-orangepi-v22-code.zip orangepi@192.168.10.3:/home/orangepi/

```bash
cd /home/orangepi
unzip -o acg720-orangepi-v22-code.zip
cd /home/orangepi/acg720_vision
python3 -c "import json; print(json.load(open('manifest.json'))['client_bundle_version'])"
sh tools/start_fpga_follow.sh --restart
sh tools/start_fpga_follow.sh --status
```

版本命令应输出22。现有开机服务会把旧2100启动参数更新为`--initial-tilt-angle 135`。即使仍手输旧的FPGA模式2100命令，v22也会明确打印迁移提示并使用现场角度表换算135°；其他手输PWM仍须满足90°下限。

`FOLLOW runtime:`和`FOLLOW prepared:`日志会打印v22、源文件哈希、实际加载的标定路径、135°请求、换算PWM、角度表反算角度与90°下限。反算角度是指令估计；普通舵机没有实测角度回传，不能把它说成机械角度反馈。

把网线接回FPGA，使用配套新位流：

1. **题5 GIMBAL TRACK**：点击TRACK FACE测试人脸；点击TRACK DOG测试小狗。只动云台，不启动底盘。点击前先让目标进入视野；首次动作先把上层准备到135°，等待FPGA确认PWM并取得3帧新画面，再锁定目标，避免用转动前的旧框。
2. **题6 FIND FACE**：夜间默认搜索人脸。云台在实测PAN行程内搜索，必要时请求底盘有限次原地转向。TURN TO FACE、GO NEAR FACE沿用车头参考与唯一雷达簇匹配，不用人脸框大小猜距离。
3. STOP取消当前任务；SIDE FOLLOW仍保留原来的小狗在车左、底盘只前后侧随。

题5的独立云台跟踪不依赖雷达、相机车头参考或物体测距。一个检测器故障不会再阻断另一个；先按目标类别筛选，再取显示目标列表，避免人脸多时把小狗挤出候选。

题6的测距仍要求雷达实际照到对应的人或物体。只有人脸图像不能证明雷达看到了同一个目标；没有唯一匹配会显示WAIT LASER MATCH或LASER AMBIGUOUS。这不阻断题5独立云台跟踪。

本轮不重装OpenCV/ONNX环境，不覆盖`config/gimbal.json`、`config/visual_task.json`或模型。新增人脸/小狗、135°启动、旧参数迁移、PWM确认/新帧、单检测器故障隔离和独立跟踪不受雷达几何影响的离线测试通过；尚需现场镜头与舵机验证。

实现核对参考：[OpenCV官方YuNet](https://github.com/opencv/opencv_zoo/blob/main/models/face_detection_yunet/README.md)、[官方人脸解码实现](https://github.com/opencv/opencv/blob/4.10.0/modules/objdetect/src/face_detect.cpp)。保留已在Pi上工作的推理实现，未要求把现有OpenCV4.5.4换成新版。
