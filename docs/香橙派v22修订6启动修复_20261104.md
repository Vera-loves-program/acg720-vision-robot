# Pi v22修订6：恢复首帧画面

修订5在画第一帧中心死区时读取了尚未建立的tracker.config，导致画面线程退出，网页显示`NoneType object has no attribute config`。这是本次预览改动引入的程序错误，不是模型、用户安装步骤或限位导致。只刷新网页不能重新启动退出的画面线程。

修订6改为从已验证配置读取死区，覆盖冷启动和save_config后tracker为空的阶段。跟踪控制、协议及FPGA保持修订5实现；保留现场标定、模型和参数，不重刷系统，不需重烧FPGA。原修订5包保留作溯源，不再部署。
