## 烧录与观察

1. 在 Gowin Designer 中打开上述 **旧工程**。顶层是 `lcd_camera_switch_top`。
2. 不运行 Synthesize 或 Place & Route，直接进入 Programmer。
3. 保持此前使用的 `GW5AT-60B / SRAM Program`，手动将 FS File 选为上述旧文件。特别注意完整目录：必须是 `lcd_camera_switch\impl\pnr`，不是 `acg720_vision_robot\impl\pnr`；两个目录里可能有同名文件。
4. 执行烧录，等待 3 秒。旧版本应该先显示此前的图片，不会出现新 UI 右侧的 CAM/DDR 状态栏。若仍看到新状态栏，说明旧版本没有成功加载。
5. 按一下 **S4 / BUTTON4**，松开后等待 3 秒。应切换到居中的 800×480 摄像头画面，上下及左右有黑边。
6. 记录图片是否出现、按 S4 后是否有摄像头画面，以及 D3、D4、D5、D6、D7 分别亮还是灭。按 S0 是整个工程复位，会返回图片模式；之后需再次按 S4。

## 如何判断

| 回退后的结果 | 能得出的结论 |
| --- | --- |
| 图片与摄像头画面都正常 | 摄像头在该配置下能工作，应继续排查新工程的改动、配置与布局 |
| 图片正常，D4 一直灭，摄像头区域黑 | 旧版本的 DDR 也没有完成校准；该版本会保持摄像头采集复位，不能据此判断摄像头损坏 |
| 图片正常，D4 亮但 D3 灭 | 摄像头初始化流程没有结束，继续检查摄像头初始化链路 |
| 图片正常，D3/D4 亮，按 S4 后 D5 亮但 D6 灭 | 校准与初始化流程已结束，但未记录摄像头帧，需要继续检查供电、XCLK、DVP 信号与采集逻辑；仍不能只凭黑屏断言摄像头损坏 |
| D3/D4/D5/D6 亮但视频黑、D7 亮 | 已观察到摄像头帧同步，仍需排查像素/FIFO/DDR 数据通路 |
| 按 S4 后 D5 不亮 | 旧工程没有识别到相机模式切换；先确认旧位流和按钮 |
| 连图片也不出现 | 问题不局限于摄像头；先确认烧录文件、供电和 LCD 连接 |

本轮只是恢复已保留的对照版本。硬件是否恢复需要用户实际烧录后确认，尚未在本次验证。
