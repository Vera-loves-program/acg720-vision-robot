# 香橙派：识别网页、连拍、复制到D盘

## 香橙派SSH终端

旧服务在当前终端运行时先Ctrl+C；正常识别网页已运行时不用重启。

```bash
cd /home/orangepi/acg720_vision
/home/orangepi/.venvs/acg720-detection/bin/python client.py gimbal --camera /dev/video0 --width 640 --height 480 --fps 15
```

保持运行，电脑浏览器开`http://127.0.0.1:8080/`。加载现有玩偶/人脸模型，默认MOCK后端，不输出真实舵机PWM；不要加`--no-detection`。若之前成功相机设备是video2等编号，沿用原编号。现有云台标定不会被清除。

## 网页打不开时：电脑PowerShell建立隧道

当前SSH已有8080转发时不用重复建立。需要时另开电脑PowerShell执行：

```powershell
ssh -N -o ServerAliveInterval=15 -o ServerAliveCountMax=3 -o ExitOnForwardFailure=yes -L 127.0.0.1:8080:127.0.0.1:8080 orangepi@192.168.10.3
```

输入密码后没有新提示正常，保持窗口开启。此命令只转发端口，不启动相机。若8080已被旧隧道占用，继续使用旧隧道。

## 拍照与保存位置

让玩偶正面照明、避免背后强灯，静止试远近和各侧面。网页应显示识别已开启。点**有目标·连拍10张**，约每0.5秒保存一张新原图，慢慢变化角度/距离。拍无目标环境用**背景·连拍10张**。

香橙派原图位置：

```text
/home/orangepi/acg720_vision/dataset/usb_captures/positive/
/home/orangepi/acg720_vision/dataset/usb_captures/negative/
```

JPG无检测框、无文字；同名JSON记录采集信息，不是人工标签。队友应对原始JPG重新标注，再补充训练。识别数据采集不需要棋盘格。

## 复制到D盘：在电脑PowerShell执行

确认提示符是`PS C:\...>`，不是`orangepi@...$`。逐行执行：

```powershell
New-Item -ItemType Directory -Force -Path "D:\小车采集照片"
```

```powershell
scp -r "orangepi@192.168.10.3:/home/orangepi/acg720_vision/dataset/usb_captures" "D:\小车采集照片"
```

输入香橙派密码，等待回到PowerShell提示符。第一次复制后电脑照片位置：

```text
D:\小车采集照片\usb_captures\positive\
D:\小车采集照片\usb_captures\negative\
```

命令不会删除香橙派上的照片。交队友原始JPG，保留JSON便于追溯，不发网页截图替代原图。
